# Project2--编程实现图片水印嵌入和提取
# 摘要
&emsp;&emsp;本实验围绕数字水印技术展开，主要研究了空间域和频域两种不同的水印嵌入与提取方法。实验基于 Python 语言实现，借助 NumPy、OpenCV 等库完成图像的处理和分析。通过对 LSB（最低有效位）、DCT（离散余弦变换）和 DFT（离散傅里叶变换）三种水印方法的实现和测试，比较了它们在不可见性和鲁棒性方面的性能差异。实验结果表明，频域方法（尤其是 DCT）在抵抗各种攻击方面表现更为出色，而 LSB 方法虽然简单但鲁棒性较差。   
# 一、实验原理
## **1.1 数字水印**：
&emsp;&emsp;数字水印是一种将特定信息（如版权信息、标识等）嵌入到数字媒体（如图像、音频、视频）中的技术。与加密技术不同，水印通常是不可见或不可听的，不会显著影响原始媒体的质量。数字水印的主要目的包括版权保护、内容认证、内容追踪等。一个完整的数字水印系统通常包括水印生成、水印嵌入、水印提取和水印检测四个主要部分。理想的水印应该具有以下特性：      
**a.不可感知性**：嵌入水印后，原始媒体的质量不应有明显下降。  
**b.鲁棒性**：水印应该能够抵抗各种常见的处理和攻击，如压缩、滤波、裁剪等。    
**c.安全性**：水印应该对未经授权的提取和篡改具有一定的抵抗力。    
<br/>

## **1.2 空间域水印方法**（LSB）：
&emsp;&emsp;LSB（最低有效位）是一种最简单且最常见的空间域水印方法。其基本原理是将水印信息嵌入到图像像素的最低有效位中。由于人眼对图像的细微变化不敏感，因此修改像素的最低位通常不会对图像的视觉质量产生明显影响。其优点是实现简单、容量大，但缺点是鲁棒性较差，容易受到各种图像处理操作的影响。   
<br/>

## **1.3 频域水印方法（DCT和DFT）**：
&emsp;&emsp;频域水印方法是将水印嵌入到图像的频域表示中。与空间域方法相比，频域方法通常具有更好的鲁棒性，因为频域表示对图像的局部变化不太敏感。   
**a.离散余弦变换（DCT）**：DCT 是一种将信号从空间域转换到频域的变换方法，广泛应用于图像和视频压缩。DCT 将图像分成多个 8×8 的块，每个块经过 DCT 变换后得到一个频域系数矩阵。其中，低频系数表示图像的整体结构，高频系数表示图像的细节信息。DCT 水印方法通常选择中频系数来嵌入水印，因为低频系数对图像质量影响较大，而高频系数容易被噪声和压缩操作破坏。在本实验中，我们选择每个 8×8 块的 (4,4) 位置的中频系数来嵌入水印。    
**b.离散傅里叶变换（DFT）**：DFT 是一种更通用的频域变换方法，它将信号转换为复数形式的频域表示。与 DCT 不同，DFT 处理的是整个图像，而不是分块处理。DFT 水印方法将水印嵌入到图像的频域中心区域，因为该区域包含了图像的主要能量信息。在本实验中，我们将水印嵌入到频域图像的中间 1/4 区域。   
<br/>  

## **1.4 水印评估指标**：
&emsp;&emsp;为了评估水印的性能，本实验使用了两个主要指标：   
**a.峰值信噪比（PSNR）**：用于衡量原始图像和水印图像之间的质量差异。PSNR值越高，表示图像质量损失越小，水印的不可感知性越好。    
**b.归一化相关系数（NCC）**：用于衡量提取的水印与原始水印之间的相似程度。NCC值越接近1，表示提取的水印与原始水印越相似，水印的鲁棒性越好。    
# 二、实验流程   
## **2.1 水印系统（Watermarking)实现**：     
&emsp;&emsp;首先实现了一个水印系统类WaterSystem，包含以下主要功能：     
**a.水印生成**：基于密钥生成随机二进制水印图案。   
**b.水印嵌入**：实现了LSB、DCT、DFT三种水印嵌入方法。   
**c.水印提取**：对应三种嵌入方法，实现了相应的水印提取方法。   
**d.性能评估**：实现了PSNR和NCC两个评价指标的计算方法。    
<dr/>

## **2.2 鲁棒性测试实现**：  
&emsp;&emsp;为了测试水印的鲁棒性，实现了一个鲁棒性测试类RobustnessTester，包含以下攻击测试：   
**a.几何攻击**：旋转、缩放、裁剪。    
**b.噪声攻击**：椒盐噪声（Salt-and Pepper Noise。     
**c.压缩性攻击**：JPEG压缩。   
**d.图像处理攻击**：对比度调整、高斯模糊。    
<dr/>  

## **2.3 实验设计**：  
&emsp;&emsp;使用Lena图像进行实验，主要步骤如下：    
**step1.水印生成**：生成随机二进制水印图案。   
**step2.水印嵌入**：分别使用LSB、DCT和DFT方法将水印嵌入到原始图像中。   
**step3.质量评估**：计算原始图像和水印图像之间的PSNR，评估水印的不可感知性。     
**step4。攻击测试**：对水印图像进行各种攻击，然后从攻击后的图像中提取水印。     
**step5.鲁棒性评估**：计算提取的水印与原始水印之间的NCC，评估水印的鲁棒性。    
**step6.结果分析**：比较三种水印方法在不同攻击下的性能表现。
<dr/>   

# 三、实验结果与分析    
| 方法 |不可感知性（原始PSNR）| 鲁棒性核心特点 | 典型攻击抗性表现 |
| :---: |  :---------------:  | :-----------: | :--------------: |
| LSB | 最高(51.15) | 空间域简单嵌入，依赖像素最低位 | 对几何攻击、强噪声、高压缩极差；对线性对比度调整意外抗性强 |
| DCT | 中等(44.15) | 分块中频嵌入，平衡质量与鲁棒性 | 对几何攻击、噪声、压缩抗性优于LSB；频噪操作让水印分散，攻击后仍可提取残留 |
| DFT | 最低(30.81) | 全局频域嵌入，依赖中心能量区域 | 对几何攻击、噪声有一定抗性，但频域全局特性导致压缩、模糊后畸变明显，NCC 波动大 |
